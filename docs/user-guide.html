RBLclass — User Guide

RBLclass is an Outlook add-in that helps you file (classify) emails into folders across your mailboxes and PST archives, with fast keyword search over your whole folder tree. It adds a task pane on the right of Outlook and an RBLclass tab on the ribbon.

Getting started

The RBLclass pane opens automatically when Outlook starts. If you close it, the RBLclass ribbon tab has four buttons:

  • RBLclass pane — show or hide the pane.
  • Refresh folders — re-scan your mailboxes so folders you created or renamed directly in Outlook show up in search.
  • Settings — all options (see the Settings reference below).
  • About — version, author and technical information.

Keyboard access to the pane: press Alt, then R (the RBLclass tab), then R again (the pane button).

Features

Folder search

Type keywords in the search box at the top of the pane. Results appear after a short pause. For each result row:

  • Single-click the row to check it as a filing destination (check several to file into all of them at once).
  • Enter files the selected mail into the highlighted folder.
  • Ctrl+Enter opens the highlighted folder in Outlook instead of filing.
  • Double-click a row to file into that folder immediately.
  • The ↗ button opens that folder in Outlook.
  • Right-click → Add subfolder… creates a sub-folder under it.
  • The ⤢ button cycles how that row shows its path (see "Search result path display" in Settings).

Tapping Ctrl on its own (press and release, without another key) toggles "List every matching folder".

Classify

Select one or more mails in Outlook, check the destination folder(s) in the pane, then click Classify (or press Enter / double-click for a single folder). The ▶ Options zone offers five per-action overrides, seeded from your settings and reset after each classify: keep a copy, remove attachments from the filed copy, include the whole conversation, strip the external-sender banner, and mark as read.

Auto-class files the selected mail(s) to wherever their conversation was last classified, without picking a folder by hand.

Undo

The Undo button — or Ctrl+Z anywhere in the pane — reverses the last classify: moved mails go back to their source folder (and are re-selected there so you can re-file them elsewhere) and filed copies are removed. Only the last classify can be undone; removed attachments cannot be restored.

Attachment management

When "Remove attachments" is on, the filed copy loses its attachments; the original (or the kept copy) is never touched. In the default "Ask what to do with each attachment" mode, a dialog lets you Delete, Save to… or Keep each attachment; a "use the same save directory" checkbox applies your choice to all of them. Encrypted (S/MIME) mails are never stripped.

Sent-item triage

Each time a mail lands in Sent Items, RBLclass can act automatically or ask you. The choices are: Move to Inbox, Move to archive folder (a folder you configure), Delete from Sent Items, or Leave in Sent Items. When a sent mail is moved to the Inbox, the pane can auto-open with that mail pinned as the next thing to file.

Send-time guards

  • Forgotten attachment: if your message body mentions an attachment (using the configured keywords) but nothing is attached, a confirmation appears before the mail goes out.
  • External recipient: before sending, a confirmation lists any recipient whose domain is not on your internal-domains list.

External-sender banner strip

Many organisations add a "this email came from outside" banner to incoming mail. Teach RBLclass that banner once (Settings → External-sender banner → Learn from selected mail), and it can strip it automatically from your replies and forwards, and from filed copies.

Settings reference

Open Settings from the RBLclass ribbon group. Every change applies and persists immediately — there is no "Apply" button, and closing is always safe.

RBLclass — Benutzerhandbuch

RBLclass ist ein Outlook-Add-in, das E-Mails schnell in Ordner über Ihre Postfächer und PST-Archive hinweg ablegt (klassifiziert), mit einer schnellen Stichwortsuche über den gesamten Ordnerbaum. Es fügt rechts in Outlook einen Aufgabenbereich und ein Menüband-Register RBLclass hinzu.

Erste Schritte

Der RBLclass-Bereich öffnet sich automatisch beim Start von Outlook. Wenn Sie ihn schließen, bietet das Menüband-Register RBLclass vier Schaltflächen:

  • RBLclass-Bereich — den Bereich ein-/ausblenden.
  • Ordner aktualisieren — Postfächer neu einlesen, damit direkt in Outlook erstellte oder umbenannte Ordner in der Suche erscheinen.
  • Einstellungen — alle Optionen (siehe unten).
  • Info — Version, Autor und technische Angaben.

Tastaturzugriff auf den Bereich: Alt, dann R (Register RBLclass), dann erneut R (Bereichsschaltfläche).

Funktionen

Ordnersuche

Geben Sie Stichwörter in das Suchfeld oben im Bereich ein. Die Ergebnisse erscheinen nach einer kurzen Pause. Pro Ergebniszeile:

  • Einfachklick auf die Zeile markiert sie als Ablageziel (mehrere markieren, um in alle gleichzeitig abzulegen).
  • Eingabe legt die ausgewählte E-Mail in den markierten Ordner ab.
  • Strg+Eingabe öffnet den markierten Ordner in Outlook, statt abzulegen.
  • Doppelklick auf eine Zeile legt sofort in diesen Ordner ab.
  • Die Schaltfläche ↗ öffnet diesen Ordner in Outlook.
  • Rechtsklick → Unterordner hinzufügen… erstellt einen Unterordner darunter.
  • Die Schaltfläche ⤢ wechselt die Pfadanzeige dieser Zeile (siehe „Pfadanzeige der Suchergebnisse" in den Einstellungen).

Ein kurzes Antippen von Strg allein (drücken und loslassen) schaltet „Alle passenden Ordner anzeigen" um.

Klassifizieren

Wählen Sie in Outlook eine oder mehrere E-Mails aus, markieren Sie im Bereich die Zielordner und klicken Sie auf Klassifizieren (oder Eingabe / Doppelklick für einen einzelnen Ordner). Der Bereich ▶ Optionen bietet fünf Überschreibungen pro Aktion, aus Ihren Einstellungen vorbelegt und nach jeder Ablage zurückgesetzt: Kopie behalten, Anhänge aus der abgelegten Kopie entfernen, gesamte Unterhaltung einbeziehen, Externe-Absender-Banner entfernen und als gelesen markieren.

Auto-Klassierung legt die ausgewählte(n) E-Mail(s) dorthin ab, wo ihre Unterhaltung zuletzt abgelegt wurde, ohne Ordnerauswahl von Hand.

Rückgängig

Die Schaltfläche Rückgängig — oder Strg+Z irgendwo im Bereich — macht die letzte Ablage rückgängig: verschobene E-Mails kehren in ihren Quellordner zurück (und werden dort erneut ausgewählt, damit Sie sie anderswo ablegen können) und abgelegte Kopien werden entfernt. Nur die letzte Ablage kann rückgängig gemacht werden; entfernte Anhänge nicht.

Anhangsverwaltung

Ist „Anhänge entfernen" aktiv, verliert die abgelegte Kopie ihre Anhänge; das Original (oder die behaltene Kopie) bleibt unberührt. Im Standardmodus „Bei jedem Anhang nachfragen" können Sie jeden Anhang löschen, unter … speichern oder behalten; ein Kontrollkästchen „denselben Speicherort verwenden" wendet die Wahl auf alle an. Verschlüsselte (S/MIME) E-Mails werden nie bereinigt.

Postausgang-Verwaltung

Jedes Mal, wenn eine E-Mail in Gesendete Elemente gelangt, kann RBLclass automatisch handeln oder nachfragen. Die Optionen sind: In den Posteingang verschieben, In Archivordner verschieben (ein von Ihnen konfigurierter Ordner), Aus gesendeten Elementen löschen oder In gesendeten Elementen belassen. Wird eine gesendete E-Mail in den Posteingang verschoben, kann sich der Bereich öffnen und diese E-Mail als nächstes Ablageziel anheften.

Sendeprüfungen

  • Vergessener Anhang: Erwähnt Ihr Text einen Anhang (über die konfigurierten Stichwörter), ist aber keiner beigefügt, erscheint vor dem Senden eine Rückfrage.
  • Externer Empfänger: Vor dem Senden werden Empfänger aufgelistet, deren Domäne nicht in Ihrer internen Liste steht.

Externe-Absender-Banner entfernen

Viele Organisationen fügen eingehenden E-Mails ein „Diese E-Mail kam von außen"-Banner hinzu. Bringen Sie RBLclass dieses Banner einmal bei (Einstellungen → Externe-Absender-Banner → Aus ausgewählter E-Mail lernen), und es kann es automatisch aus Antworten und Weiterleitungen sowie aus abgelegten Kopien entfernen.

Einstellungsreferenz

Öffnen Sie die Einstellungen über die RBLclass-Menübandgruppe. Jede Änderung wird sofort übernommen und gespeichert — es gibt keine „Übernehmen"-Schaltfläche, und Schließen ist immer sicher.

RBLclass — Guide d'utilisation

RBLclass est un complément Outlook qui aide à classer rapidement les e-mails dans des dossiers, à travers vos boîtes aux lettres et archives PST, avec une recherche par mots-clés sur toute l'arborescence. Il ajoute un volet à droite d'Outlook et un onglet RBLclass sur le ruban.

Premiers pas

Le volet RBLclass s'ouvre automatiquement au démarrage d'Outlook. Si vous le fermez, l'onglet RBLclass du ruban propose quatre boutons :

  • Volet RBLclass — afficher ou masquer le volet.
  • Actualiser les dossiers — réanalyser les boîtes pour que les dossiers créés ou renommés directement dans Outlook apparaissent.
  • Paramètres — toutes les options (voir plus bas).
  • À propos — version, auteur et informations techniques.

Accès clavier au volet : Alt, puis R (onglet RBLclass), puis R à nouveau (bouton du volet).

Fonctionnalités

Recherche de dossiers

Saisissez des mots-clés dans le champ de recherche en haut du volet. Les résultats apparaissent après une courte pause. Pour chaque ligne :

  • Clic simple sur la ligne pour la cocher comme destination (cochez-en plusieurs pour classer dans toutes à la fois).
  • Entrée classe le message sélectionné dans le dossier en surbrillance.
  • Ctrl+Entrée ouvre le dossier en surbrillance dans Outlook au lieu de classer.
  • Double-clic sur une ligne pour classer immédiatement dans ce dossier.
  • Le bouton ↗ ouvre ce dossier dans Outlook.
  • Clic droit → Ajouter un sous-dossier… crée un sous-dossier.
  • Le bouton ⤢ fait défiler le mode d'affichage du chemin de cette ligne (voir « Affichage du chemin des résultats » dans les paramètres).

Une brève pression sur Ctrl seul (appuyer puis relâcher) bascule « Lister tous les dossiers correspondants ».

Classer

Sélectionnez un ou plusieurs messages dans Outlook, cochez le(s) dossier(s) de destination dans le volet, puis cliquez sur Classer (ou Entrée / double-clic pour un seul dossier). La zone ▶ Options propose cinq réglages ponctuels, initialisés depuis vos paramètres et réinitialisés après chaque classement : conserver une copie, supprimer les pièces jointes de la copie classée, inclure toute la conversation, supprimer la bannière d'expéditeur externe et marquer comme lu.

Classement auto classe le(s) message(s) là où leur conversation a été classée la dernière fois, sans choisir de dossier à la main.

Annuler

Le bouton Annuler — ou Ctrl+Z n'importe où dans le volet — annule le dernier classement : les messages déplacés reviennent dans leur dossier source (et y sont resélectionnés pour les reclasser ailleurs) et les copies classées sont supprimées. Seul le dernier classement est annulable ; les pièces jointes supprimées ne sont pas restaurées.

Gestion des pièces jointes

Lorsque « Supprimer les pièces jointes » est activé, la copie classée perd ses pièces jointes ; l'original (ou la copie conservée) n'est jamais touché. Dans le mode par défaut « Demander pour chaque pièce jointe », une boîte de dialogue permet de Supprimer, Enregistrer sous… ou Conserver chaque pièce jointe ; une case « utiliser le même dossier » applique votre choix à toutes. Les messages chiffrés (S/MIME) ne sont jamais modifiés.

Gestion des envois

Chaque fois qu'un message arrive dans les Éléments envoyés, RBLclass peut agir automatiquement ou vous demander. Les choix sont : Déplacer vers la boîte de réception, Déplacer vers le dossier d'archivage (un dossier que vous configurez), Supprimer des éléments envoyés ou Laisser dans les éléments envoyés. Quand un message envoyé est déplacé vers la boîte de réception, le volet peut s'ouvrir avec ce message épinglé comme prochain à classer.

Contrôles à l'envoi

  • Pièce jointe oubliée : si le corps du message mentionne une pièce jointe (via les mots-clés configurés) mais qu'aucune n'est jointe, une confirmation apparaît avant l'envoi.
  • Destinataire externe : avant l'envoi, une confirmation liste tout destinataire dont le domaine n'est pas dans votre liste interne.

Suppression de la bannière d'expéditeur externe

Beaucoup d'organisations ajoutent aux messages entrants une bannière « cet e-mail vient de l'extérieur ». Apprenez cette bannière à RBLclass une fois (Paramètres → Bannière d'expéditeur externe → Apprendre depuis le message sélectionné), et il pourra la retirer automatiquement de vos réponses et transferts, ainsi que des copies classées.

Référence des paramètres

Ouvrez les paramètres depuis le groupe RBLclass du ruban. Chaque changement s'applique et persiste immédiatement — il n'y a pas de bouton « Appliquer », et fermer est toujours sans risque.

Dossiers de pièces jointes favoris

Pré-indexez des répertoires Windows pour que le sélecteur « Enregistrer sous… » (dans la boîte de dialogue des pièces jointes) trouve un emplacement aussi vite qu'un dossier Outlook. Les sous-dossiers sont indexés jusqu'à une profondeur de 4.

Langue

RBLclass suit la langue d'Outlook par défaut (avec repli sur l'anglais). Vous pouvez la forcer à English, Français ou Deutsch. Le changement prend effet après le redémarrage d'Outlook.

Actualiser l'index des dossiers

L'index des dossiers est construit automatiquement en arrière-plan au démarrage d'Outlook. Si vous créez ou renommez un dossier directement dans Outlook et qu'il n'apparaît pas dans la recherche, cliquez sur Actualiser les dossiers sur le ruban.

Suggestions et signalement de problèmes

RBLclass est maintenu sur GitHub : github.com/reboulip/rblclass/issues. Ouvrez-y un ticket pour signaler un bogue ou proposer une fonctionnalité. Si vous ne pouvez pas accéder à GitHub depuis votre poste, utilisez le canal de contact du guide d'installation. Pour aider au diagnostic, joignez le dernier fichier journal depuis %LocalAppData%\RBLclass\logs\.

Ce fichier est autonome (pas d'images ni de styles externes) — il peut être envoyé en pièce jointe unique, ou déposé à côté de l'installateur sur l'espace partagé interne.
