= RBLclass — Guide d'utilisation =

RBLclass est un complément Outlook qui aide à classer rapidement les e-mails dans des dossiers, à travers vos boîtes aux lettres et archives PST, avec une recherche par mots-clés sur toute l'arborescence. Il ajoute un volet à droite d'Outlook et un onglet '''RBLclass''' sur le ruban.

== Premiers pas ==

Le volet RBLclass s'ouvre automatiquement au démarrage d'Outlook. Si vous le fermez, l'onglet '''RBLclass''' du ruban propose quatre boutons :

* '''Volet RBLclass''' — afficher ou masquer le volet.
* '''Actualiser les dossiers''' — réanalyser les boîtes pour que les dossiers créés ou renommés directement dans Outlook apparaissent.
* '''Paramètres''' — toutes les options (voir plus bas).
* '''À propos''' — version, auteur et informations techniques.

Accès clavier au volet : '''Alt''', puis '''R''' (onglet RBLclass), puis '''R''' à nouveau (bouton du volet).

== Fonctionnalités ==

=== Recherche de dossiers ===

Saisissez des mots-clés dans le champ de recherche en haut du volet. Les résultats apparaissent après une courte pause. Pour chaque ligne :

* '''Clic simple''' sur la ligne pour la cocher comme destination (cochez-en plusieurs pour classer dans toutes à la fois).
* '''Entrée''' classe le message sélectionné dans le dossier en surbrillance.
* '''Ctrl+Entrée''' ''ouvre'' le dossier en surbrillance dans Outlook au lieu de classer.
* '''Double-clic''' sur une ligne pour classer immédiatement dans ce dossier.
* Le bouton '''↗''' ouvre ce dossier dans Outlook.
* Clic droit → '''Ajouter un sous-dossier…''' crée un sous-dossier.
* Le bouton '''⤢''' fait défiler le mode d'affichage du chemin de cette ligne (voir « Affichage du chemin des résultats » dans les paramètres).

Une brève pression sur '''Ctrl''' seul (appuyer puis relâcher) bascule ''« Lister tous les dossiers correspondants »''.

=== Classer ===

Sélectionnez un ou plusieurs messages dans Outlook, cochez le(s) dossier(s) de destination dans le volet, puis cliquez sur '''Classer''' (ou '''Entrée''' / double-clic pour un seul dossier). La zone '''Options''' propose cinq réglages ponctuels, initialisés depuis vos paramètres et réinitialisés après chaque classement : conserver une copie, supprimer les pièces jointes de la copie classée, inclure toute la conversation, supprimer la bannière d'expéditeur externe et marquer comme lu.

'''Classement auto''' classe le(s) message(s) là où leur conversation a été classée la dernière fois, sans choisir de dossier à la main.

=== Annuler ===

Le bouton '''Annuler''' — ou '''Ctrl+Z''' n'importe où dans le volet — annule le dernier classement : les messages déplacés reviennent dans leur dossier source (et y sont resélectionnés pour les reclasser ailleurs) et les copies classées sont supprimées. Seul le dernier classement est annulable ; les pièces jointes supprimées ne sont pas restaurées.

=== Gestion des pièces jointes ===

Lorsque ''« Supprimer les pièces jointes »'' est activé, la copie classée perd ses pièces jointes ; l'original (ou la copie conservée) n'est jamais touché. Dans le mode par défaut ''« Demander pour chaque pièce jointe »'', une boîte de dialogue permet de Supprimer, Enregistrer sous… ou Conserver chaque pièce jointe ; une case ''« utiliser le même dossier »'' applique votre choix à toutes. Les messages chiffrés (S/MIME) ne sont jamais modifiés.

=== Gestion des envois ===

Chaque fois qu'un message arrive dans les '''Éléments envoyés''', RBLclass peut agir automatiquement ou vous demander. Les choix sont : '''Déplacer vers la boîte de réception''', '''Déplacer vers le dossier d'archivage''' (un dossier que vous configurez), '''Supprimer des éléments envoyés''' ou '''Laisser dans les éléments envoyés'''. Quand un message envoyé est déplacé vers la boîte de réception, le volet peut s'ouvrir avec ce message épinglé comme prochain à classer.

=== Contrôles à l'envoi ===

* '''Pièce jointe oubliée''' : si le corps du message mentionne une pièce jointe (via les mots-clés configurés) mais qu'aucune n'est jointe, une confirmation apparaît avant l'envoi.
* '''Destinataire externe''' : avant l'envoi, une confirmation liste tout destinataire dont le domaine n'est pas dans votre liste interne.

=== Suppression de la bannière d'expéditeur externe ===

Beaucoup d'organisations ajoutent aux messages entrants une bannière « cet e-mail vient de l'extérieur ». Apprenez cette bannière à RBLclass une fois (Paramètres → Bannière d'expéditeur externe → ''Apprendre depuis le message sélectionné''), et il pourra la retirer automatiquement de vos réponses et transferts, ainsi que des copies classées.

== Référence des paramètres ==

Ouvrez les paramètres depuis le groupe RBLclass du ruban. Chaque changement s'applique et persiste immédiatement — il n'y a pas de bouton « Appliquer », et fermer est toujours sans risque.

=== Bannière d'expéditeur externe ===

''Apprendre depuis le message sélectionné'' capture la bannière du message sélectionné ; ''Oublier'' l'efface ; ''Diagnostiquer'' indique si le message actuel correspond. Puis trois options (toutes désactivées par défaut, utiles seulement une fois une bannière apprise) : retirer à la réponse/au transfert, retirer au classement, et retirer lors du Classement auto.

=== Dossiers de pièces jointes favoris ===

Pré-indexez des répertoires Windows pour que le sélecteur « Enregistrer sous… » (dans la boîte de dialogue des pièces jointes) trouve un emplacement aussi vite qu'un dossier Outlook. Les sous-dossiers sont indexés jusqu'à une profondeur de 4.

=== Langue ===

RBLclass suit la langue d'Outlook par défaut (avec repli sur l'anglais). Vous pouvez la forcer à English, Français ou Deutsch. Le changement prend effet après le redémarrage d'Outlook.

== Actualiser l'index des dossiers ==

L'index des dossiers est construit automatiquement en arrière-plan au démarrage d'Outlook. Si vous créez ou renommez un dossier directement dans Outlook et qu'il n'apparaît pas dans la recherche, cliquez sur '''Actualiser les dossiers''' sur le ruban.

== Suggestions et signalement de problèmes ==

RBLclass est maintenu sur GitHub : [https://github.com/reboulip/rblclass/issues GitHub Issues]. Ouvrez-y un ticket pour signaler un bogue ou proposer une fonctionnalité. Si vous ne pouvez pas accéder à GitHub depuis votre poste, utilisez le canal de contact du guide d'installation. Pour aider au diagnostic, joignez le dernier fichier journal depuis <code>%LocalAppData%\RBLclass\logs\</code>.
