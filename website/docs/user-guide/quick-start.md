# Quick start

This is the two-minute version: file your first email. For the full feature and
settings reference, see the [Complete walkthrough](walkthrough.md).

## 1. Open the pane

The **RBLclass pane** opens automatically when Outlook starts. If you closed it,
open it again from the **RBLclass** ribbon tab → **RBLclass pane**, or with the
keyboard: press ++alt++, then ++r++ (the RBLclass tab), then ++r++ again (the
pane button).

## 2. Select the mail(s) to file

In Outlook, select one email — or several — that you want to move out of your
inbox into a folder.

## 3. Find the destination folder

In the pane's search box, type a few keywords from the folder's name. Results
appear after a short pause. You don't need the full name or the path — a couple
of distinctive words is enough.

## 4. File it

You have several ways to file, pick whichever feels natural:

| Action | What happens |
| --- | --- |
| **Double-click** a result row | Files the selected mail(s) into that folder immediately. |
| Highlight a row and press ++enter++ | Files into the highlighted folder. |
| **Single-click** one or more rows, then **Classify** | Checks each row as a destination; **Classify** files into all checked folders at once. |
| Click **Auto-class** | Files to wherever this conversation was last classified — no folder picking needed. |

That's it — the mail moves to the destination folder.

## 5. Made a mistake? Undo

Press ++ctrl+z++ anywhere in the pane (or click **Undo**) to reverse the last
classify: moved mails go back where they came from, and any filed copies are
removed. Only the **last** classify can be undone.

!!! tip "Open a folder instead of filing"
    ++ctrl+enter++ on a highlighted result *opens* that folder in Outlook
    instead of filing into it — handy when you just want to go look at a folder.
    The **👁** button on a result row does the same.
